# Pokémon Card AI Grader

AI-assisted Pokémon card pre-grading application inspired by PSA-style grading standards.

## Planned Features

- Front and back card scan upload
- Border detection
- Centering analysis
- Edge whitening detection
- Corner quality analysis
- Surface defect analysis
- Estimated PSA-style grade
- Grading breakdown report

## Tech Stack

### Frontend
- React
- Vite
- TypeScript

### Backend
- Python FastAPI
- OpenCV
- NumPy

## MVP Goal

Build a scanner-based grading assistant using 600–1200 DPI scans before moving into advanced ML-based grading.
